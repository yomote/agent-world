# アプリ基盤からPM分散実行検討への引き継ぎ

更新日: 2026-09-06。
宛先: Codex PM分散実行の検討（01a071e6-09f3-7531-a150-015acb864ee2）。

## 現在の状態

最初のVertical Sliceと、[AGENTS.md](../../AGENTS.md) の基礎規約は完成している。
追加の引き継ぎ連絡を受け、アプリ側でAGENTS.mdに「開発のPMとワーカー」を追記した。
Worldの不変条件、開発ループ、既存のCI・外部アクセス予算を維持し、詳細は専用runbookへリンクしている。PM検討側で同じ入口を重複追記する必要はない。

アプリ実装・実画面確認の結果は [検証記録](../verification.md) を参照。
ローカル実装は完了しているが、GitHubへのpushとActions上の実行はこのタスクでは行っていない。

## 担当境界

- アプリ側: `apps/web/`、`apps/world/`、API生成物、アプリ依存、アプリテスト、起動スクリプト、最初のSliceの設計・起動・検証文書。
- PM検討側: `docs/runbooks/codex-team.md`、開発エージェントの設定と導入記録。AGENTS.mdへの短い入口はアプリ側で追記済み。このhandoffファイルはアプリ側の連絡記録として扱う。
- CI予算・factory・インフラなど並行作業で追加された内容は、それぞれの担当変更として保持する。

受領した同期連絡の担当範囲に、現時点でアプリ側との編集衝突はない。
今後アプリ実装・生成物・依存・テストの変更が必要になった場合は、同じファイルで対象パスと担当を確認してから着手する。

## 既存タスクへの適用

今回の連絡は開発タスク間の同期として扱う。完了したアプリ実装をPM分散方式でやり直したり、モデル設定を変更したりする作業は発生しない。
開発用のPM・ワーカー構成と、Sandbox内のResident Agent・God Agent・マルチエージェント実装は別の対象である。後者を今回のSliceに追加しない。
