## 共通規約への入口

アプリ担当の引き継ぎ後、2026-09-06に `AGENTS.md` に次の入口が追記済みであることを確認した。以下は当時の旧版の記録であり、現在のPM実務禁止方針により廃止した。現行の入口は `AGENTS.md` と [PMワークフロー](../runbooks/pm-workflow.md) を正典とする。

```markdown
## 開発のPMとワーカー

- 開発作業では、メイン担当をPMとし、具体的に独立したタスクはサブエージェントへ委任する。PM自身も判断・調整などの有用な作業を並行して進める。委任のためだけにタスクを細分化しない。
- PMはAstraを基本とし、複雑な実装はSol、通常実装はTerra、限定調査はLuna、独立レビューはSolを明示して使い分ける。子エージェントは担当タスクを実行し、PMの役割を継承しない。
- 並行セッションの担当範囲を確認し、同じファイルを無調整で編集しない。実行中のタスクの担当は合意なく変更しない。
- モデル指定、限定した文脈の受け渡し、レビュー、共有ディレクトリでの注意は [Codexチーム運用](docs/runbooks/codex-team.md) に従う。CIと外部アクセスの予算は引き続き全担当が守る。
```

今動いている他セッションに、この方式が遡って適用されたとはみなさない。新たに切り出せるタスクから使う。
